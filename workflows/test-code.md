description: Test the current project without modifying any files and provide a testing report
---

Use the `code-tester` skill.

IMPORTANT:
This workflow is strictly read-only.

Do NOT create, modify, delete, rename, move, or overwrite any files.
Do NOT fix any bugs.
Do NOT apply suggested code changes.

Follow this process:

1. Inspect the current project.
2. Identify changed files.
3. Run appropriate safe tests and checks.
4. Analyze failures.
5. Identify bugs and their root causes.
6. Do NOT fix or modify anything.
7. Provide suggested fixes only in the final report.
8. Provide a final testing report.

The final report must include:

- Tests executed
- Tests passed
- Tests failed
- Bugs found
- Severity of each issue
- File and line number when available
- Root cause
- Suggested fix
- Security issues, if any
- Confirmation that no files were modified
